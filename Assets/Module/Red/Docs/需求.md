# Red 红点系统需求

目标：参考 TileScape 的分段前缀树，在用户指定的 `Assets/Module/Red/` 提供红点计数、父级汇总、变化订阅及 UGUI 显示。

## 范围与责任

- 业务方拥有路径命名、数据源与计算规则，写入某路径的自身值。红点核心只维护计数、树结构和订阅；父节点可以同时有自身值和子节点。
- 组合入口创建服务，将本地接口注入业务与视图，并负责结束该实例。独立服务之间状态隔离，不建立全局单例或服务定位器。
- 首版不包含持久化、服务端同步、业务计算回调、图结构多父节点、规则编辑器、优先级红点类型、帧末批处理或自动轮询。布尔显示由合计值是否大于零决定。
- 核心不依赖 Unity 对象；UGUI 适配负责对象生命周期。三包目前未提供红点、UI 或注册器 API，本模块不预造包级接线，也不迁移参考项目的依赖。

## 行为与验收

### 路径与计数

| 情境 | 要求与可判定结果 |
|---|---|
| 路径 | 以 `.` 分段，按 `StringComparer.Ordinal` 区分大小写；拒绝 null、空串、空段及任何空白字符，不自动修剪、改大小写或接受转义。`Shop`、`Shop.Gold` 是不同节点，`Shopper` 不属于 `Shop`。隐藏根只作容器，不对外寻址或累计计数。 |
| 自身值与合计 | 每个可寻址节点的合计 = 自身值 + 直接子节点合计；自身值为非负 `int`。设置 `Shop=2`、`Shop.Gold=3`、`Shop.Diamond.A=4` 后，查询 `Shop` 得 9，`Shop.Diamond` 得 4；隐式父节点可查询、写入和订阅。 |
| 修改完成 | 设置是覆盖自身值；先完整提交目标及全部祖先的合计，再开始同步通知。操作返回时整条链一致，不依赖 Update；回调查询任一相关节点也得到已提交值。重复设置同一自身值不通知。 |
| 未知路径 | 查询返回 0，且不创建节点；设置按需创建路径。有效路径的零值订阅允许先于业务数据存在。 |
| 清除子树 | `ClearSubtree` 将目标及后代的自身值归零，更新祖先，保留现有订阅。清除未知路径或再次清除均无通知；后续重新写值仍能驱动原视图。清除不影响兄弟分支。 |
| 边界与溢出 | 负值抛 `ArgumentOutOfRangeException`；任何可寻址节点合计超过 `int.MaxValue` 时整次设置抛 `OverflowException`，数值、树结构和通知均不改变。不同顶层独立累计，不因隐藏根求和溢出。null 路径抛 `ArgumentNullException`，空字符串及其他非法路径抛 `ArgumentException`。 |
| 节点回收 | 清零或最后一个订阅释放后，递归裁剪自身值为零、无订阅且无后代的节点；有订阅的零值路径保留。动态路径反复创建、清除、退订后不持续积累无用节点。 |

### 通知与失败

| 情境 | 要求与可判定结果 |
|---|---|
| 订阅 | 每次订阅返回独立 `IDisposable` token，并同步向新监听发送一次当前合计；同一委托订阅两次即有两份独立监听，释放一份不影响另一份。null 回调抛 `ArgumentNullException`。传入委托作为一次订阅调用；组合委托内部遵循 C# 调用语义，模块不拆分，异常隔离以订阅为单位。 |
| 变化派发 | 仅在合计变化时通知；受影响节点按绝对深度降序，同深度按完整路径 Ordinal 升序，同节点按注册顺序，每节点本轮最多一次。订阅本身不通知已有监听。 |
| 退订 | token 释放立即生效，重复释放安全；回调内可退订自身或其他监听，尚未开始的已退订监听不再调用。当前已进入的回调自然结束。 |
| 回调重入 | 通知期间允许查询、token 释放及所有者销毁服务；拒绝设置、清除和新订阅，抛 `InvalidOperationException`，包括同值写入与未知路径清除。首版不引入重入命令队列或递归通知。 |
| 变化回调失败 | 单个回调抛错后继续其余有效监听，整轮结束以 `AggregateException` 汇总原异常。数值已经提交，不回滚；调用方不可把通知异常当作写入未发生而盲目重试。 |
| 初次通知失败 | 初次回调抛错时，只撤销本次订阅并回收空节点，再抛 `AggregateException`，不留下未返回 token 的监听。不回滚回调已合法完成的其他退订或服务销毁；先退订／销毁再抛错仍汇总错误。 |

### 生命周期与 UI

| 情境 | 要求与可判定结果 |
|---|---|
| 线程 | 核心限定构建线程调用，跨线程操作抛 `InvalidOperationException` 且不改状态。Unity 宿主在主线程创建、绑定、写入与释放；构建线程亲和性不等于核心能识别 Unity 主线程。后台结果须由业务切回主线程并确认会话有效。 |
| 服务结束 | 所有者先停止数据生产、解绑视图，再销毁服务。销毁立即使实例失效并清除数值、监听与树；重复销毁安全，旧 token 可继续幂等释放。其他旧实例操作抛 `ObjectDisposedException`，不重建服务。 |
| 回调内销毁 | 即时失效，跳过尚未开始的监听，当前回调自然返回；有已捕获异常仍在外层收尾时汇总。初次订阅回调主动销毁服务且未抛错时，可返回已失效 token。旧回调收尾不得清理或改写新实例。 |
| 显示 | 合计为 0 时隐藏标记，大于 0 时显示；可选 UGUI `Text` 显示实际合计，首版不做 `99+`、缩写或类型优先级。被切换显隐的对象必须是绑定组件宿主的子物体，不能是宿主自身或祖先，避免隐藏红点导致自动退订。 |
| 首次绑定与池复用 | 显式绑定服务与路径。有配置时启用即订阅刷新，禁用时释放 token、隐藏标记并保留配置；再次启用取得最新值。未绑定的 OnEnable 不订阅，仅隐藏已配置的合法子标记，无配置不算错误；未配置或非法标记在 Bind 时校验，不误操作宿主或祖先。销毁时解绑并释放引用。禁用 Bind 只保存配置，不调用服务探测是否已释放。 |
| 重复绑定与切换 | 同实例同路径重复绑定幂等。更换路径或会话实例时先结束旧订阅，再建立新订阅，不显示旧计数；旧 token 只关联旧实例。显式解绑清空配置并隐藏标记。 |
| 绑定失败 | null service 抛 `ArgumentNullException`，路径沿用核心规则，标记缺失或不是合法子物体抛 `ArgumentException`；校验失败保留原绑定。有效非 null 服务是否已释放由实际 Subscribe 判断。首次或 OnEnable 订阅失败，若本次绑定仍有效，清配置、释放订阅、隐藏标记并报告异常；不清除后来建立的绑定，可显式重绑恢复。 |

前置条件同时违规时允许报告任一匹配的错误；单一违规必须符合上表异常类型。

## 实施与验收入口

[核心任务](Tasks/实现前缀树红点核心.md)定义接口与缓存前缀树；[视图任务](Tasks/实现红点视图绑定与集成验证.md)负责真实服务与 UGUI 的最终集成。本文与两个 Task 构成完整规范，外部参考不是实施前置。完整路径缓存等优化、集合与内部字段可自行选择；多套实现采用共同验收，并隔离工作区，避免同名类和程序集冲突。

## 生成文件与即时环境

根目录的 `.csproj/.sln` 是 Unity 生成物，部分条目仍引用已不存在的源码或测试路径。实际源码和 asmdef/asmref 才能证明程序集存在，生成物更新与验证按[工程标准](06_工程实施与验收标准.md)处理。

Editor 是否打开、进程与项目路径、各仓库并发修改是执行时核查的即时状态。子模块独立保存源码，主仓提交不能自动纳入子模块未提交文件。
